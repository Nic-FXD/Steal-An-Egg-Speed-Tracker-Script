HOW TO USE: execute the script inside any roblox executor.

Set as autoexecute: paste it inside your executor's folder (Example: Autoexecute) folder.

Script GUI Features:

- Speed Stat: Displays your current speed in real-time.
- Initial Speed: Displays your past speed before using the treadmill.
- Treadmill Detection: Shows your current treadmill level.
- Time Tracker: Display treadmill session's time, time automatically start & stop before/after using the treadmill.
- Sessions: Display past sessions.
